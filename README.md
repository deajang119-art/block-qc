# 블록포장 품질검측 (GSS-QC-BLK)

블록포장 현장 검측용 웹앱. 설치 없이 브라우저에서 동작하며, 홈 화면에 추가하면 앱처럼 열립니다.
한 번 열면 오프라인에서도 동작합니다(서비스워커 캐시).

**바로 열기 → https://deajang119-art.github.io/block-qc/**

## 검측 항목

| 항목 | 판정 기준 | 근거 |
|---|---|---|
| 평탄성(요철) | 3m 직선자, 가장 오목한 곳 10mm 이내 | LH 전문시방서 41740 3.7.1 가 |
| 구배(경사) | 명시 구배 대비 ±0.4% | 41740 3.7.1 나 |
| 블록 고저차(단차) | 블록-블록, 블록-경계블록 2mm 이내 | 41740 3.7.1 다 |
| 줄눈 폭 | 밀착·균일, 2mm 표준(상한 3mm) | 41740 3.4 다 |
| 줄눈 선형(통직도) | 기준선 대비 ±3mm (사내 제안값) | 41740 3.4 마를 정량화 |

보도 종·횡단경사 상한은 국토교통부 「보도 설치 및 관리 지침」을 병행 적용합니다.

## 사용법

1. **현장정보** 입력 → 기록·리포트에 그대로 실립니다.
2. **① 줄눈** — 사진 촬영 → 축척(길이를 아는 2점 + 실제 mm) → 기준선 2점 → 줄눈 위 5점 이상.
   사진 위를 직접 누르지 말고, 확대해서 화면 중앙 조준점(⊕)에 맞춘 뒤 「점 찍기」를 누릅니다.
3. **② 경사** — 3m 직선자 위에 폰을 올리고 센서 시작 → **영점 보정(180° 반전 2회)** → 값 고정.
4. **③ 평탄성** — 3m 직선자를 놓고 자와 노면 사이 최대 간극을 거치별로 입력(자 양단 750mm 제외).
5. **기록** — A4 리포트 인쇄 또는 CSV 내보내기.

## 주의

- 허용오차 ±0.4%는 각도로 약 0.23°로, 보급형 폰 센서의 분해능과 같은 수준입니다.
  경계값이 나오면 디지털 경사계·레벨 측량으로 재확인하십시오. 이 앱은 1차 검측(스크리닝) 도구입니다.
- 사진 판독은 촬영각·원근의 영향을 받습니다. 판정이 허용값 ±20% 안에 걸리면 실측으로 확인하십시오.
- 기록은 브라우저 저장영역에만 남습니다. 구간이 끝나면 CSV·리포트로 내보내 보관하십시오.
- 공사시방서에 다른 값이 있으면 공사시방서가 우선합니다.
